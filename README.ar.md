## قائمة المزايا الكاملة

| الفئة | المزايا |
|---|---|
| أنماط العرض | **المصحف** (صفحتان متجاورتان: الفردية يمينًا والزوجية يسارًا)، **النص والترجمة**، **اختبار الحفظ** |
| أنواع المصحف | حفص، رواية ورش، حفص بالتجويد الملون (604 صفحات بصور من خادم الجامعة الأصلي) |
| التفاعل مع المصحف | انقر الآية مباشرة في الصفحة → تمييز ذهبي + حلقات زرقاء لنتائج البحث |
| طبقة الترجمة | نص الترجمة يظهر عائمًا فوق الصفحة عند موضع كل آية |
| القراء | **43 قارئًا** + رواية ورش، مرتل / مجود / معلم (الحصري، عبد الباسط، المنشاوي، السديس، ماهر العفاسي وغيرهم) |
| الترجمات | **22 لغة** — الإنجليزية، الإندونيسية، الملايو، العربية (4 صيغ)، الأردية، الروسية وغيرها |
| التفاسير | **9 كتب** — الجلالين (إندونيسي)، الميسر، ابن كثير، السعدي، البغوي، القرطبي، الطبري، الإعراب، التفهيم (روسي) |
| التفسير المضمّن | يظهر التفسير أسفل الآية المختارة في نمط النص |
| التلاقة (صوت الترجمة) | ترجمة صوتية: الإنجليزية، الفرنسية، الأردية، البوسنية |
| المشغّل الصوتي | آية بآية، انتقال تلقائي بين الآيات والسور، تكرار 1×–10×/∞، **تكرار نطاق آيات**، **وضع المعلم** (إعادة دورية)، البسملة والاستعاذة تلقائيًا، مستوى الصوت، **سرعة التشغيل 0.5×–2×** |
| الإظهار والإخفاء | مفاتيح لإظهار/إخفاء الترجمة والتفسير المضمّن ولوحة التفسير وطبقة الترجمة |
| التنقل | السورة، الآية، الصفحة، الجزء — كما في الموقع الأصلي |
| البحث | البحث في القرآن كاملًا → الانتقال إلى الآية مع **تحديد النتائج بحلقات زرقاء في المصحف** |
| وضع الحفظ | اختبار حفظ عشوائي من نطاق سور/آيات مع إخفاء النص وتشغيل الصوت |
| هدف الختم | تقدم الأجزاء الثلاثين + سلسلة الأيام المتتالية — تُسجَّل الصفحات تلقائيًا عند فتحها |
| خريطة الحفظ | خريطة حرارية لـ 604 صفحات: محفوظ / يحتاج مراجعة / لم يُحفظ بعد |
| العلامات المرجعية | تمييز الآيات المفضلة والانتقال إليها سريعًا |
| اختبار الحفظ المتسلسل | «ما الآية التالية؟» — اختبار متسلسل لكل سورة مع النقاط |
| قائمة تشغيل السور | طابور من عدة سور، لكل سورة قارئ مختلف |
| مشغّل مصغّر | نافذة صغيرة تبقى فوق كافة النوافذ |
| بطاقة الآية | تصدير الآية مع الترجمة كصورة PNG ونسخ النص |
| التذكير اليومي | إشعار في علبة النظام في الوقت المحدد |
| وضع التركيز | إخفاء شريط الأدوات واللوحات، Esc للخروج |
| الوضع الليلي | سمة داكنة للتطبيق كاملًا |
| محتوى إلهامي | **آية اليوم** (تظهر عند بدء التطبيق)، 12 فئة تحفيزية (القلق، الرزق، الزواج، السعي وغيرها)، أدعية «ربنا»، وصول سريع لآية الكرسي والمعوذات |
| مؤشر السجدة | آيات السجدة الواجبة والمستحبة في شريط الحالة |
| التحميل الجماعي | تحميل صفحات المصحف كاملة أو نطاق مختار، وتحميل صوت سورة كاملة — للعمل دون اتصال |
| اختصارات لوحة المفاتيح | ← → تنقل بين الآيات • Space تشغيل/إيقاف • PgUp/PgDn تنقل الصفحات • Ctrl+F بحث • Esc الخروج من وضع التركيز |
| الذاكرة المؤقتة | تُخزَّن الصوتيات وصور المصحف والترجمات والتفاسير تلقائيًا |
| حفظ الموضع | السورة والآية والقارئ والنمط والتكبير والسمة — تُحفظ تلقائيًا |
| الأيقونة | أيقونة تطبيق مخصصة |

## التحميل والتشغيل

**الأسهل:** حمّل النسخة المحمولة من [Google Drive](https://drive.google.com/drive/folders/1A0AvGWNaHMU2bZtrvoES25RUh-pr6VMx?usp=sharing) أو [إصدارات GitHub](https://github.com/linducip2208/alquran/releases) وشغّلها مباشرة — لا حاجة لتثبيت أي شيء.

**من الشيفرة المصدرية:**
1. ثبّت [.NET 7 SDK](https://dotnet.microsoft.com/download/dotnet/7.0)
2. `dotnet build QuranDesktop -c Release`
3. `dotnet run --project QuranDesktop`

يلزم الاتصال بالإنترنت عند أول فتح للمحتوى؛ وبعد تخزينه مؤقتًا يعمل دون اتصال.

## مصادر البيانات

جميع المحتويات تُجلب مباشرة من خادم **[quran.ksu.edu.sa](https://quran.ksu.edu.sa)** (مشروع المصحف الإلكتروني، جامعة الملك سعود):

- **الصوتيات:** `https://quran.ksu.edu.sa/ayat/mp3/{قارئ}/{SSS}{AAA}.mp3` (+ الاستعاذة والبسملة والترجمات الصوتية)
- **صور المصحف:** `https://quran.ksu.edu.sa/ayat/safahat1/{صفحة}.png` (حفص)، `/warsh/{صفحة}.png`، `/tajweed_png/{صفحة}.png`
- **التفاسير / الترجمات / البحث / إحداثيات التمييز:** `https://quran.ksu.edu.sa/interface.php?ui=pc&do=tafsir|tarjama|search|hilites`
- **بيانات الصفحات والأجزاء:** `https://quran.ksu.edu.sa/js/quran-data.js` (المصدر: [Tanzil.net](https://tanzil.net)، رخصة GPL)
- **روابط التفاسير على الويب:** `https://quran.ksu.edu.sa/tafseer/{كتاب}/sura{s}-aya{a}.html`
